## 前言

如果你经常写博客、记笔记、写文档，一定逃不开 Markdown。它是一种轻量级标记语言，用简单的符号就能排版出漂亮的文档。比起 Word 的点点点，Markdown 让你专注于内容本身。

这篇教程从最基础的语法讲起，逐步覆盖进阶用法，还包括了本博客（Firefly 主题）特有的扩展语法。一篇文章，帮你彻底搞定 Markdown 写作。

## 基础语法

### 标题

用 `#` 号来创建标题，几个 `#` 就是几级标题：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

实际效果：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

> 一篇文章通常只用一个一级标题（由文章标题自动生成），正文从二级标题开始。

### 文本格式

Markdown 支持多种文本样式：

| 语法 | 效果 | 说明 |
|------|------|------|
| `**粗体**` | **粗体** | 双星号包裹 |
| `*斜体*` | *斜体* | 单星号包裹 |
| `***粗斜体***` | ***粗斜体*** | 三星号包裹 |
| `~~删除线~~` | ~~删除线~~ | 双波浪号包裹 |
| `` `行内代码` `` | `行内代码` | 反引号包裹 |

你也可以用 `_` 替代 `*`，效果一样：`__粗体__` = `**粗体**`。

### 链接

创建超链接的语法是 `[链接文字](URL)`：

```markdown
[Google](https://www.google.com)
[带提示的链接](https://www.google.com "鼠标悬停时显示")
```

实际效果：

[Google](https://www.google.com)
[带提示的链接](https://www.google.com "鼠标悬停时显示")

**自动链接**：直接写 URL 会自动变成可点击的链接：

```
https://www.google.com
```

### 图片

插入图片的语法是 `![替代文字](图片地址)`：

```markdown
![风景图片](https://example.com/photo.jpg)
```

也可以设置图片大小（部分 Markdown 解析器支持）：

```markdown
<img src="https://example.com/photo.jpg" width="300" />
```

### 列表

**无序列表**用 `-`、`*` 或 `+` 开头：

```markdown
- 第一项
- 第二项
  - 嵌套项
  - 嵌套项
- 第三项
```

实际效果：

- 第一项
- 第二项
  - 嵌套项
  - 嵌套项
- 第三项

**有序列表**用数字加 `.` 开头：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

实际效果：

1. 第一步
2. 第二步
3. 第三步

> 数字不需要严格递增，写 `1. 1. 1.` 也会自动编号为 1、2、3。

**任务列表**（Task List）用 `- [ ]` 或 `- [x]`：

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个待办
```

实际效果：

- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个待办

### 引用

用 `>` 创建引用块：

```markdown
> 这是一段引用文字。
> 可以写多行。
>
> 甚至可以分段。
```

实际效果：

> 这是一段引用文字。
> 可以写多行。
>
> 甚至可以分段。

引用可以嵌套：

```markdown
> 一级引用
>> 二级引用
>>> 三级引用
```

### 分割线

用三个或更多的 `-`、`*` 或 `_` 创建分割线：

```markdown
---
***
___
```

实际效果：

---

***

___

## 进阶语法

### 表格

用 `|` 分隔列，用 `-` 分隔表头和内容：

```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |
```

实际效果：

| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |

**对齐方式**通过在分隔行添加冒号控制：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:-------:|-------:|
| 左     | 中      | 右     |
```

实际效果：

| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:-------:|-------:|
| 左     | 中      | 右     |

### 代码块

**行内代码**用单个反引号包裹：`` `code` ``

**代码块**用三个反引号包裹，可以指定语言：

````markdown
```python
def hello():
    print("Hello, Markdown!")
```
````

实际效果：

```python
def hello():
    print("Hello, Markdown!")
```

支持的语言非常多，常见的有 `javascript`、`typescript`、`html`、`css`、`python`、`java`、`go`、`rust`、`bash` 等。

**缩进式代码块**：用四个空格或一个 Tab 缩进也能创建代码块（不推荐，不如反引号方便）。

### 链接引用

把 URL 提取出来统一管理，让正文更干净：

```markdown
这是一个[长链接][1]，还有[另一个][2]。

[1]: https://www.example.com/very/long/url
[2]: https://www.another.com/url
```

实际效果：

这是一个[长链接][1]，还有[另一个][2]。

[1]: https://www.example.com/very/long/url
[2]: https://www.another.com/url

### 脚注

用 `[^标记]` 创建脚注：

```markdown
这是一个带脚注的例子[^1]。

[^1]: 这是脚注的内容，会显示在页面底部。
```

### 转义字符

用反斜杠 `\` 转义特殊字符：

```
\*这不是斜体\*    →    \*这不是斜体\*
\`这不是代码\`    →    \`这不是代码\`
```

### HTML 混写

Markdown 支持直接嵌入 HTML：

```html
<details>
<summary>点击展开</summary>

这里是折叠的内容，点击后才显示。

</details>
```

实际效果：

<details>
<summary>点击展开</summary>

这里是折叠的内容，点击后才显示。

</details>

## Firefly 扩展语法

以下是 Firefly 主题特有的 Markdown 扩展功能，让你的博客内容更丰富。

### Admonitions（提醒块）

提醒块可以高亮显示重要信息，支持多种风格。语法是在引用块 `>` 后面加上类型标记：

```markdown
> [!NOTE]
> 这是一条**注意**信息，用于补充说明。

> [!TIP]
> 这是一个**提示**，给出有用的建议。

> [!IMPORTANT]
> 这是一条**重要**信息，需要特别关注。

> [!WARNING]
> 这是一个**警告**，可能导致问题。

> [!CAUTION]
> 这是一条**危险**操作提醒，请谨慎处理。
```

实际效果：

> [!NOTE]
> 这是一条**注意**信息，用于补充说明。

> [!TIP]
> 这是一个**提示**，给出有用的建议。

> [!IMPORTANT]
> 这是一条**重要**信息，需要特别关注。

> [!WARNING]
> 这是一个**警告**，可能导致问题。

> [!CAUTION]
> 这是一条**危险**操作提醒，请谨慎处理。

你也可以自定义标题：

```markdown
> [!NOTE] 自定义标题
> 这条提醒有一个自定义标题。
```

### Mermaid 图表

Mermaid 是一个基于文本的图表工具，可以用简单的语法创建流程图、时序图、甘特图等。在代码块中指定语言为 `mermaid` 即可：

#### 流程图

````markdown
```mermaid
graph TD
    A[开始] --> B{是否需要?}
    B -->|是| C[执行操作]
    B -->|否| D[跳过]
    C --> E[结束]
    D --> E
```
````

实际效果：

```mermaid
graph TD
    A[开始] --> B{是否需要?}
    B -->|是| C[执行操作]
    B -->|否| D[跳过]
    C --> E[结束]
    D --> E
```

#### 时序图

````markdown
```mermaid
sequenceDiagram
    participant 用户
    participant 浏览器
    participant 服务器
    用户->>浏览器: 输入网址
    浏览器->>服务器: 发送请求
    服务器-->>浏览器: 返回页面
    浏览器-->>用户: 显示内容
```
````

实际效果：

```mermaid
sequenceDiagram
    participant 用户
    participant 浏览器
    participant 服务器
    用户->>浏览器: 输入网址
    浏览器->>服务器: 发送请求
    服务器-->>浏览器: 返回页面
    浏览器-->>用户: 显示内容
```

#### 饼图

````markdown
```mermaid
pie
    title 技术栈占比
    "JavaScript" : 35
    "TypeScript" : 25
    "Python" : 20
    "Go" : 15
    "其他" : 5
````

## 写在最后

Markdown 的核心理念是**让写作回归内容本身**。常用的语法也就那么几种，遇到不会的查一下就行，没必要一次全记住。写得多了，自然就熟了。
