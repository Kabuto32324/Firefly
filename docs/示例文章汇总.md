## Frontmatter 字段参考

| 字段 | 说明 | 示例 |
|------|------|------|
| title | 文章标题 | "我的第一篇文章" |
| published | 发布日期 | 2024-01-01 |
| description | 文章描述（SEO） | "这是我的第一篇博客文章" |
| image | 封面图路径 | ./cover.jpg 或 "api"（随机封面） |
| tags | 标签数组 | [Foo, Bar] |
| category | 分类 | Front-end |
| draft | 是否草稿 | false |
| lang | 文章语言 | zh-CN |
| pinned | 是否置顶 | false |
| comment | 是否允许评论 | true |
